# Security Policy

## Supported versions

Security fixes apply to the latest release on the default branch (`main`) of this
repository. Older commits are not supported.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security reports.

- **Email:** [security@keenable.ai](mailto:security@keenable.ai)
- **GitHub:** Use [Private vulnerability reporting](https://github.com/keenableai/keenable-grok-plugin/security/advisories/new) on this repository if you prefer.

Include a description, steps to reproduce, and impact if known. We aim to
acknowledge reports within a few business days.

This plugin connects Grok Build to Keenable's hosted MCP at
`https://api.keenable.ai/mcp`. Vulnerabilities in that service should also be
reported to Keenable using the same contact path.
